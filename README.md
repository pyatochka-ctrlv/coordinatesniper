# 🎮 Координатний снайпер — Minecraft Education (Урок 5)

Інтерактивний навчальний тренажер для уроку 5 «Таємниці координат» (Minecraft Education).
Створений для демонстрації на екрані або проекторі вчителем під час фронтальної гри з усім класом.

---

## 🚀 Як задеплоїти на GitHub Pages (2 прості способи)

### Спосіб 1: Найпростіший (через завантаження файлів з архіву) — 2 хвилини

1. **Створіть репозиторій на GitHub**:
   * Перейдіть на [github.com/new](https://github.com/new).
   * Назвіть репозиторій, наприклад: `coordinate-sniper`.
   * Зробіть його **Public** (Публічним) і натисніть **Create repository**.

2. **Завантажте файли з архіву**:
   * Розархівуйте файл `coordinate-sniper-gh-pages.zip`.
   * У вашому новому репозиторії на GitHub натисніть **Add file** ➔ **Upload files**.
   * Перетягніть **всі файли та папки** з розпакованого архіву (`index.html`, папку `assets`, `.nojekyll`).
   * Натисніть **Commit changes**.

3. **Увімкніть GitHub Pages**:
   * Перейдіть у вкладку **Settings** репозиторію.
   * У лівому меню оберіть **Pages**.
   * У розділі **Build and deployment**:
     * **Source**: виберіть `Deploy from a branch`.
     * **Branch**: виберіть `main` (або `master`), папка `/ (root)`.
   * Натисніть **Save**.
   * Через 30–60 секунд оновіть сторінку: зверху з'явиться посилання на ваш сайт:
     `https://<ваш-логін>.github.io/coordinate-sniper/`

---

### Спосіб 2: Через GitHub Actions (для розробників з вихідним кодом)

1. Створіть репозиторій і завантажте весь вихідний код проєкту.
2. Перейдіть у **Settings** ➔ **Pages** ➔ **Source** ➔ виберіть **GitHub Actions**.
3. Файл робочого процесу `.github/workflows/deploy.yml` вже налаштований у проєкті: він автоматично збере проєкт (`npm run build`) та опублікує на GitHub Pages при кожному пуші.

## 💻 Керування з клавіатури для вчителя:

Поки діти хором називають координати:
* `←` / `→` — змінює координату **X** (вліво / вправо);
* `↑` / `↓` — змінює координату **Z** (або **Y** на 2-му рівні);
* `Пробіл (Space)` — постріл / кидок сніжки;
* `Enter` — перехід до наступного раунду.
